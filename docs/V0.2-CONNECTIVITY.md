# MountCaM V0.2 — Connectivity proof

## Scope
Prove one authorized Tekron X2-WQ-BL live stream on Android over mobile data.
Do not modify camera configuration, reset devices, or expose router ports.

## Verified from project handover
- iCSee works on LAN and mobile data for both cameras.
- Local RTSP requires authentication.
- FunSDK compatibility and independent P2P access are NOT verified.

## Candidate
XM FunSDK Android (see https://github.com/xmcamera/libxmfunsdk).
Do not add a dependency or redistribute vendor binaries until the SDK license,
developer account requirements, and app credential handling are reviewed.

## Architecture
CameraGateway isolates SDK integration from Compose screens.
The initial UnconfiguredCameraGateway intentionally does not connect or claim
a working stream. Connection identifiers and credentials must never be hardcoded
or committed to the public repository.

## Next gates
1. Confirm exact vendor SDK licensing, SDK version and Android support.
2. Obtain authorized application credentials via the vendor's developer portal
   without committing them or transmitting them through GitHub Actions.
3. Test one device's authenticated local connection on the phone.
4. Test its independent P2P connection on mobile data (Wi-Fi disabled).
5. Render actual frames, handle failures and measure reconnect behavior.
6. Only then consider second camera, PTZ, audio and SD playback.

## Security
No full device UID, QR pairing data, passwords, tokens, recordings or
developer secrets in code, logs, GitHub issues, artifacts or screenshots.
Do not open RTSP/HTTP/admin ports to the public Internet.
Keep the existing iCSee setup operational.
